# Healthcare Data Governance and Cleaning

## Project Overview
This project demonstrates basic healthcare data governance, data cleaning, and data quality validation using synthetic, de-identified patient records provided for practice during an internship task.

The objective is to organize patient data, document its fields, apply appropriate cleaning rules, and record data quality checks without inventing or changing clinical values without justification.

## Project Objectives
- Understand field classification and data privacy.
- Create a data dictionary describing the dataset fields.
- Clean inconsistent text formatting where appropriate.
- Validate data types, ranges, missing values, and duplicate patient IDs.
- Document data quality issues and actions in an exception log.

## Workbook Structure
The Excel workbook contains the following sheets:

- `raw_data` — source practice records.
- `cleaned_data` — cleaned version of the records.
- `data_dictionary` — field definitions and classifications.
- `validation` — data quality validation checks.
- `exception_log` — recorded exceptions and corrective actions.
- `Read_Me` — project instructions and documentation.

## Privacy and Data Governance
The dataset is described as synthetic, de-identified training data. It is used for learning and portfolio demonstration, not for real patient care or clinical decision-making.

## Tools Used

- GitHub for project hosting and documentation

## Learning Outcomes
This project provides practice in data cleaning, data quality validation, documentation, and privacy-aware handling of healthcare-related datasets.
